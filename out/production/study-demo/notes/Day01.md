#  一.计算机语言
## 1. 计算机语言（顶层概念）

**定义**：人与计算机硬件沟通、编写程序指令的所有语言总称，作用是下达运算、存储、输入输出指令。

包含三类：机器语言、汇编语言、高级编程语言。

## 2. 机器语言（最低级，计算机原生语言）

1. **本质**：纯二进制代码，只有 `0` 和 `1`
2. **运行特性**：CPU 可以**直接识别、直接执行**，不需要任何翻译程序
3. 优缺点
    
    ✅ 执行速度最快，无中间转换损耗
    
    ❌ 极难阅读、记忆、修改；不同 CPU 架构代码完全不通用（无移植性）
4. 示例：一段加法指令 `10111000 00000011`
5. 使用场景：几乎不会人工手写，仅逆向破解、硬件底层分析时会看到

## 3. 汇编语言（低级语言，机器语言的 “符号翻译版”）

1. **本质**：用英文助记符替代二进制，**一条汇编指令严格对应一条机器码**，一一映射
2. **运行要求**：必须通过「汇编器」翻译成机器语言才能运行
3. 常用指令：`MOV`（赋值）、`ADD`（加法）、`JMP`（跳转）
4. 优缺点
    
    ✅ 比二进制易读，执行效率接近机器语言
    
    ❌ 依旧绑定硬件，换 CPU 就要重写代码；需要手动管理寄存器、内存
5. 示例（计算 1+2）

asm

```
MOV AX, 1
ADD AX, 2
```

6. 使用场景：操作系统内核、硬件驱动、单片机底层、软件逆向

## 4. 编程语言（狭义 = 高级编程语言，大众最常用）

日常说的 “写代码、编程语言” 均指这一类，高度脱离硬件细节。

1. **本质**：贴近人类自然逻辑，屏蔽 CPU、寄存器、内存地址等底层细节
2. 两大运行方式
    
    - 编译型：C/C++、Go、Rust（整体编译为机器码再运行）
    - 解释型：Python、JavaScript、PHP（逐行实时翻译执行）
    - 虚拟机型：Java（先转字节码，由虚拟机运行）
    
3. 优缺点
    
    ✅ 简单易懂、开发效率高、跨平台能力强
    
    ❌ 执行速度慢于汇编 / 机器语言
