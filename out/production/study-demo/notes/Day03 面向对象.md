# 1.类和对象
## 1. 类表示归纳，对象为具体的事物
类class，引用数据类型
构建对象：new 类名（）；
类是对象的模板，对象是类的实例。![[assets/521f3fd54dd93f778788a31a4f847c13.png]]
对象是将内存地址赋给了变量，所以变量引用了内存的对象。
空对象：   = null；
## 2.属性
属性类型 属性名称 = 属性值
如果在类里声明属性时进行初始化，所有对象共同享有。
默认初始化。0   0.0    false    
char = 空字符
引用数据类型 = null
变量只能在当前大括号内使用，
而属性不仅在当前类中使用，随对象在其他范围使用。
变量使用前必须初始化。

## 4.静态
类中声明属性会全体对象都有。
把与对象无关，与类有关的叫做静态，在方法或属性前加static
先有类，再有对象。
成员属性方法可以访问静态。static不许有成员属性方法。
## 5.包
package后边，写import
import java.util.*表示所有的类。
不同包里的同名类，需要写全。
## 6.构造方法
JVM自动添加构造方法
基本语法      类名（）{}
1.没有void关键字。
2.方法名类名完全相同
3.可以传参
对象不能调用构造方法。
## **7.继承**
类存在父子关系，子类可以直接继承父类
一个子类只能有一个父类，一个父类能有多个子类。
super
this，默认情况子类里有this关键字
创建子类对象前，会分别调用一次父类构造方法；
